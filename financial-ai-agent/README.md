# FinAgent AI service

Окремий FastAPI-сервіс для AI-функцій FinAgent.

- `POST /categorize` — вибір категорії за описом транзакції;
- `POST /chat` — відповіді на фінансові запитання та формування очікуваних дій;
- `POST /audit` — виявлення й пояснення нетипових витрат.

Сервіс не записує дані до бази. Дії з чату повертаються бекенду й виконуються лише після підтвердження користувача.

```bash
python -m pytest tests -v
uvicorn main:app --reload
```
