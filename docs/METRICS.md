# Перевірка якості FinAgent

Метрики в цьому проєкті використовуються як допоміжні засоби розробки, а не як гарантія якості фінансових рекомендацій.

## Автоматизовані перевірки

| Частина | Перевірки |
|---|---|
| Backend | unit-тести usecase, JWT, шифрування, AI-клієнт, rate limit |
| AI-сервіс | read-інструменти, перетворення дій, статистичне виявлення аномалій |
| Frontend | ESLint і production build |
| Конфігурація | `docker compose config`, YAML-файли CI |

## Eval-набір

Каталог `eval/` містить сценарії для перевірки:

- визначення типу запиту `FINANCIAL`, `SCENARIO`, `ACTION`, `GENERAL`;
- вибору дії та ключових полів у структурованому виклику інструмента.

Eval потребує запущеного AI-сервісу та реального виклику моделі, тому результат може змінюватися. Його слід описувати як експериментальну перевірку, а не як гарантовану точність.

## Що не вимірюється

У репозиторії немає підтверджених вимірювань затримки, вартості запитів, точності персональних рекомендацій або довготривалої якості прогнозів. Такі твердження не слід використовувати в документації без окремого відтворюваного експерименту.
