# Бакалаврський обсяг FinAgent

## Простий опис

FinAgent — вебзастосунок для обліку особистих фінансів з AI-асистентом. Він допомагає вести доходи й витрати, переглядати базову аналітику, працювати з фінансовими цілями та ставити запитання про власні дані природною мовою.

## Архітектура простими словами

- **Frontend** показує сторінки, форми, таблиці, графіки та AI-чат.
- **Backend** перевіряє користувача, виконує фінансові операції та надає REST API.
- **AI-сервіс** розуміє природну мову, пропонує категорії, відповідає в чаті та пояснює нетипові витрати.
- **База даних** зберігає користувачів, категорії, транзакції, цілі, історію чату та журнал дій.

AI-сервіс не змінює базу даних напряму. Він формує очікувану дію для підтвердження, після чого backend перевіряє та виконує її.

## Головні модулі

Автентифікація, профіль, транзакції, категорії, аналітика, цілі, дашборд, AI-чат, прості сценарії «що, якби», загальні фінансові пропозиції та виявлення нетипових витрат.

## Додаткові модулі

Частково інтегрована AI-категоризація, Monobank, налаштовуване розташування віджетів, eval-набір, GitHub Actions і GitLab CI.

## Що показати на захисті

- поділ на frontend, backend, AI-сервіс і базу даних;
- ізоляцію даних користувачів;
- підтвердження AI-дій перед зміною даних;
- поєднання звичайного фінансового обліку з природномовним інтерфейсом;
- чесні межі сценаріїв «що, якби» та рекомендацій.

## Межі проєкту

Система не є повністю автономним агентом, професійним фінансовим радником, платформою прогнозування або системою фонових сповіщень. Monobank, CI та eval є додатковими частинами, а не суттю дипломної роботи.
